# Select and compose images with intent

Define each image's job before choosing it: document an actual project, explain a product, establish atmosphere or support a story. For portfolios, authentic project images are the evidence. A plausible stock or generated image must not be presented as completed client work.

## Select a coherent set

Look at candidate images, not just filenames or search descriptions. Prefer useful subject matter, sufficient resolution, a workable crop and a consistent photographic treatment across the set. Check usage rights and retain source/license information for sourced assets. Use supplied or existing project media first. Ask for missing authentic evidence when it matters; use clearly identified placeholders only where appropriate.

Choose the hero for both its subject and its composition. If text sits beside it, consider how the subject faces into the layout. If text overlays it, plan negative space and reliable contrast at every crop. A striking photograph that loses the important subject on mobile is a poor hero choice.

## Art-direct a portfolio

Build an image plan before uploading: **project / source / intended role / aspect ratio / crop or focal point / alt text**. Select one strong lead image per project, then a small set that adds information: overall view, detail, use or context. Remove near duplicates. Do not give unrelated projects the same generic imagery merely to fill a grid.

Use consistent ratios for comparable grid items when it helps scanning; let selected features use a different scale intentionally. Check how the title and metadata sit with each image. A project page should explain the work with verified details such as scope, role or year, not use a gallery as a substitute for all context.

## Prepare and verify

Upload through the site's native media API, use the returned attachment ID, and discover the actual featured-image/gallery fields before assigning them. Keep captions and credits distinct from alternative text. Describe the relevant visible information for meaningful images; decorative images can use empty alt text. Consider the image's context and avoid repeating nearby text unnecessarily.

Use appropriately sized responsive renditions and reserve their dimensions in the layout. Avoid serving a large original file for a small thumbnail. Keep the lead image available promptly and defer lower-page imagery where supported. Inspect real frontend requests and crops after saving: attachment metadata, generated sizes, builder behavior and caching can affect what visitors see.

If imagery is weak, revise the composition or identify the missing asset. Additional shadows, overlays and decorative shapes rarely repair an irrelevant image.
